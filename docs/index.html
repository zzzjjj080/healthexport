ヘルスケア書き出し

iPhone用アプリ — サポートページ

iPhoneのヘルスケアに貯まった記録を、いつも使っているAIにそのまま渡せる1枚のテキストにまとめるアプリです。 目的を選ぶだけで、期間も項目も、AIへの依頼文も決まります。

使いかた

  1. アプリを開き、ヘルスケアの読み取りをすべて許可します。
  2. 6つの目的から1つ選びます。迷ったら「ふだんの管理」。
  3. 必要なら期間を「−／＋」で変えます（2週間〜1年）。
  4. 書き出すを押します。
  5. 「コピー」でチャット欄に貼るか、「共有」でテキストファイルとして送ります。

よくある質問

「記録が1件も見つかりませんでした」と出ます

次の2つのどちらかです。アプリの側からは区別ができません。

  • その期間に本当に記録が無い（期間を長くしてみてください）
  • ヘルスケアの読み取りが許可されていない

許可の確認は、iPhoneの「設定」→「プライバシーとセキュリティ」→「ヘルスケア」→「ヘルスケア書き出し」から行えます。 アプリの中では「書き出されるデータ」を開いて「項目や形式を変える」→ 一番上の 「ヘルスケアの許可をもう一度求める」からも確認できます。

書き出したテキストが長すぎて貼れません

書き出したあとの画面に文字数とおおよそのトークン数が出ます。「大きすぎます」と表示されたときは、 期間を短くするか、項目を減らしてください。 「記録を1件ずつ全部」にした項目があると一気に大きくなります（心拍は3ヶ月で10万件を超えます)。 ふだんは「1日ごとにまとめる」のままで十分です。

持っている端末を登録しなくていいのですか

必要ありません。選んだ期間を実際に調べて、記録がある項目だけを並べます。 Apple Watchやイヤホンで測っているものは、記録が入っていれば自動的に対象になります。

数字がヘルスケアアプリと違って見えます

歩数のように、iPhoneとApple Watchが両方書き込む項目があります。 そのまま足すと実際より多くなるため、ヘルスケアが重複を除いたあとの値を使っています。 睡眠も、2つの端末が同じ夜を記録していれば重なりを潰してから数えます。

英語で書き出せますか

できます。「項目や形式を変える」→「形式」→「書き出す言語」から English を選んでください。 見出しも列名も依頼文も英語になります。
