ヘルスケア書き出し — 2026年8月30日

ヘルスケア書き出しは、あなたの記録を外部に送信しません。 読み取ったデータは、あなたのiPhoneの中だけで扱われます。開発者がそれを見ることはできません。 ただし、書き出したテキストを誰に渡すかは、あなたが決めます。 その先での扱いについては、下の「書き出したあとについて」をお読みください。

収集する情報

ありません。アカウントの登録も、メールアドレスの入力も不要です。 利用状況の解析（アナリティクス）や、広告のための計測も行っていません。 アプリが通信するのは、設定の「開発者にコーヒーを奢る」（App内課金）に関わるときだけです。

アプリが読み取る情報

あなたが許可した範囲で、iPhoneのヘルスケア（HealthKit）から次のような記録を読み取ります。 読み取りのみで、ヘルスケアへの書き込みは行いません。

  • アクティビティ … 歩数、歩行＋走行距離、上った階数、消費エネルギー、エクササイズ時間、スタンド時間、ワークアウト
  • 心臓 … 心拍数、安静時心拍数、心拍変動、歩行時平均心拍数、心肺機能
  • 呼吸・体温 … 血中酸素、呼吸数、手首皮膚温の変化
  • 睡眠 … 睡眠時間とその内訳
  • からだ … 体重、体脂肪率
  • 歩行の質 … 歩行速度、歩幅、歩行の非対称性
  • 聴覚 … ヘッドフォン音量、環境音レベル
  • こころ … マインドフルネス、気分の記録

読み取るのは、あなたが画面で選んだ期間と項目に限られます。 臨床記録（医療機関から取り込んだ健康記録）は読み取りません。

端末に保存するもの

アプリが端末内に保存するのは、次の設定だけです。ヘルスケアの記録そのものは保存しません。

  • 選んでいる目的、期間、項目
  • 書き出す形（言語、表のかたち、区切りなど）

書き出したテキストは、共有のために一時ファイルとして作られることがありますが、 アプリを削除すれば一緒に消えます。

書き出したあとについて

ここが、このアプリでいちばん大事な点です。

書き出したテキストには、あなたの健康に関する情報が入っています。 それをAIサービスやメール、メッセージなど、アプリの外へ渡すかどうかは、あなたが決めます。 渡したあとの扱いは、渡した先のサービスのプライバシーポリシーに従います。 このアプリの管理は及びません。

渡す前に、次の点を確かめることをおすすめします。

  • そのサービスが、送った内容を学習や改善に使うかどうか
  • 本名が入っていないか（端末の名前は「〇〇のApple Watch」のように名前を含むことがあります。 「項目や形式を変える」→「形式」→「端末の名前を入れる」を切ると外せます）
  • 渡す必要のない項目が入っていないか

第三者への提供

行いません。ヘルスケアから読み取った情報を、広告やマーケティングに使うことはありません。 データ仲介業者を含む第三者に販売・提供することもありません。 ヘルスケアのデータが端末の外へ出ることはないため、開発者がそれを受け取る手段がありません。

お子さまについて

このアプリは、特に子どもを対象としたものではありません。 年齢に関する情報を集めることもありません。
